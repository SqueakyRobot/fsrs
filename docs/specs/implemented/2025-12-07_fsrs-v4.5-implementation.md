# FSRS v4.5 Implementation Specification

**Status**: Complete
**Created**: 2025-12-07
**Implemented**: 2025-12-08
**Version**: 1.0.0
**Algorithm Version**: FSRS v4.5 (with v6 compatibility)

## Summary

Implementation of the Free Spaced Repetition Scheduler (FSRS) v4.5 algorithm as a pure TypeScript library optimized for edge runtime environments (Cloudflare Workers, Vercel Edge, Deno Deploy).

## Features Delivered

### Core Algorithm
- **FSRS v4.5**: Full implementation of 17-parameter algorithm
- **V6 Compatibility**: Accepts 21-parameter sets for advanced users
- **Power-law forgetting curve**: R(t, S) = (1 + F · t/S)^(-0.5)
- **DSR Model**: Difficulty, Stability, Retrievability tracking

### API
- `repeat()`: Calculate outcomes for all 4 ratings
- `scheduleWithGrade()`: Single rating scheduling (discrete or continuous)
- `autoRating()`: Response time to continuous grade conversion
- `getRetrievability()`: Current retention probability
- `getNextInterval()`: Preview interval for rating
- `createEmptyCard()`: Initialize new cards
- `isLapse()`: Utility for lapse detection

### Technical
- **Zero dependencies**: Minimal bundle size (~3.3KB gzipped)
- **Edge runtime compatible**: Uses `crypto.getRandomValues()` for fuzzing
- **Type-safe**: Full TypeScript with strict mode
- **Immutable API**: All methods return new objects
- **Dual format**: ESM and CJS output via tsup

## Test Coverage

- 147 tests across 4 test suites

- Simulation tests verify convergence behavior
- Edge cases: long intervals, repeated lapses, epoch dates
- JSON serialization verified
- Immutability guaranteed
